# 잠꼬대 자물쇠 미로 🌙

졸린 잠꾸러기의 뒤섞인 잠꼬대를 듣고 자물쇠를 열어, 꿈 조각 5개를 모아 **새벽 문**으로 탈출하는 미로 게임입니다.
Python(tkinter)으로 만든 미니 프로젝트를 웹 버전으로 옮겼습니다.

**▶ 플레이:** https://pakuyama.github.io/sleepy-maze/

## 게임 방법
- **이불 방**에서 시작합니다. 선으로 이어진 옆 방으로만 갈 수 있어요.
- 잠긴 방을 누르면 문 앞에 서고, 잠꾸러기가 문제를 잠꼬대로 중얼거립니다. 정답을 입력해 문을 엽니다.
- 문을 열면 꿈 조각을 하나 얻어요. 잠긴 방 7개 중 5개를 열면 **새벽 문**이 열립니다.
- 체력은 ♥♥♥. 틀릴 때마다 1씩 줄고 0이 되면 탈출 실패입니다.

## 요소 반영
| 요소 | 반영한 곳 |
|---|---|
| 잠꾸러기 | 힌트를 잠꼬대로 들려주는 캐릭터 |
| 미로 | 9칸(3×3) 방 지도, 이어진 방으로만 이동 |
| 졸린 | 처음엔 글자까지 거꾸로 → 틀릴수록 잠이 깨서 힌트가 또렷해짐 |
| 모으다 | 꿈 조각 5개를 모아야 새벽 문이 열림 |
| 돌발 상황: 엉뚱한 값 입력 | 입력 검사(전각 숫자, 공백, 한글 숫자, 소수, 범위 등). 체크를 끄면 `ValueError` 재현 |
